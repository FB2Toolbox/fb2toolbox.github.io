# История изменений

Все заметные изменения в этом проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [Unreleased]

## [1.9.2] - 2025-11-06

Исправлен номер версии в файле.

## [1.9.1] - 2025-11-06

Исправлены мелкие ошибки и внесены улучшения в тестовый код.

### Изменено
- Миграция тестов с MSTest на xUnit
- Замена фреймворка тестирования на xUnit с использованием AwesomeAssertions для более удобных и читаемых утверждений
- Рефакторинг больших тестовых файлов на более мелкие и сфокусированные модули
- Обновление атрибутов тестов (`[TestClass]`, `[TestMethod]`) на эквиваленты xUnit (`[Fact]`, `[Trait]`)
- Модернизация методов утверждений с использованием fluent-синтаксиса (например, `Should().Be`, `Should().Throw`)
- Улучшена читаемость и поддерживаемость тестового кода
- Обновление зависимостей проекта с добавлением xUnit и AwesomeAssertions

## [1.9.0] - 2025-11-05

> Автор [Дмитрий](https://github.com/jonny3D)

### Добавлено
- Поддержка drag'n'drop файлов из FB2Toolbox в проводник (копирование-вставка)
- Поддержка drag'n'drop файлов между экземплярами FB2Toolbox (импорт файлов)
- Возможность группировки элементов по сериям
- Новые типы группировки
- Функция фильтрации и удаления файлов
- Возможность удаления файлов из списка и физического удаления файлов
- Переменные окружения, используемые при выполнении команды открытия
- Парсинг каталогов при drag'n'drop
- Парсинг файлов при drag'n'drop

### Изменено
- Обновление до Visual Studio 2022 и .NET Framework 4.8
- Оптимизация производительности
- Улучшена форма редактора свойств: автоматическое включение проверки обновлений при изменении текста
- Настройка конфигурации

### Исправлено
- Исправлено ограничение максимальной длины серии, которое иногда включало год издания
- Исправлен пропуск существующих файлов
- Исправлен парсинг имен файлов на кириллице
- Опциональная очистка списка перед drag'n'drop файлов
