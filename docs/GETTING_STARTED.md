# Начало работы

**FB2 Toolbox** — бесплатная программа для эффективного переименования, перемещения и перекодирования книг в формате FB2.

## Быстрый старт

Работа с программой предельно проста:

1. **Добавьте файлы** — через меню `Список → Добавить...` (файлы или каталоги)
2. **Отметьте файлы** — поставьте "птички" на файлы для обработки (или `Список → Отметить все`)
3. **Выберите действие** — из меню `Действия`
4. **Следите за выполнением** — в нижней части главного окна программы

## Работа с файлами

### Типы выделения файлов

FB2 Toolbox различает три типа выделения:

- **Отмеченные файлы** — помечены "птичкой" слева от иконки
- **Выделенные файлы** — подсвечены синим в списке
- **Текущий файл** — одиночный выделенный файл для быстрых действий

> **Важно:** Все операции из меню `Действия` выполняются только над **отмеченными** файлами. Синее выделение игнорируется.

### Быстрая отметка файлов

Выделение используется для удобной групповой отметки:

1. Кликните по группе файлов (например, "Толстой: Война и Мир")
2. Поставьте или снимите отметку с одного из выделенных файлов
3. Все выделенные файлы будут отмечены (или отметка будет снята)

### Контекстное меню (текущий файл)

Кликните правой кнопкой мыши по файлу для вызова контекстного меню. Это позволяет выполнять быстрые действия над одним файлом, не затрагивая отметки остальных.

## Действия над отмеченными файлами

> **Примечание:** Файлы с ошибками нельзя отметить.

| Действие | Назначение | Использование | Примечания |
| :--- | :--- | :--- | :--- |
| **Изменение кодировки** | Перекодирование файлов в выбранную кодировку | `Действия → Перекодировать в → (выберите кодировку)` | Выполняется только для файлов, чья текущая кодировка отличается от выбранной. |
| **Перемещение файлов** | Перемещение файлов в целевой каталог согласно заданному **профилю** | `Действия → Переместить → Профиль: XYZ` | Программа запросит целевой каталог, пустые каталоги после перемещения удаляются автоматически. |
| **Копирование файлов** | Копирование файлов в целевой каталог согласно заданному **профилю** | `Действия → Копировать → Профиль: XYZ` | Исходные файлы остаются на месте. |
| **Переименование на месте** | Изменение только имени файла согласно **профилю**, без перемещения | `Действия → Переименовать на месте → Профиль: XYZ` | Используется, если у вас уже есть собственная структура каталогов. |

## Работа с архивами

FB2 Toolbox также может производить большинство операций над книгами в архивах `.fb2.zip`.

> **Важное ограничение:** Поддерживается только одна книга на архив!

### Архивирование

Упаковка файлов `.fb2` в ZIP-архивы.

**Что происходит:**
- Каждый файл `.fb2` упаковывается в отдельный архив с тем же именем
- Расширение архива: `.fb2.zip`
- Исходный файл `.fb2` удаляется после успешной архивации

### Распаковка

Извлечение книги `.fb2` из архива `.fb2.zip`.

**Что происходит:**
- Книга извлекается из архива
- Архив `.fb2.zip` удаляется после успешной распаковки

## Контекстное меню (действия над текущим файлом)

Вызовите контекстное меню правой кнопкой мыши на файле в списке.

### Открыть файл

Запускает файл `.fb2` в программе, зарегистрированной в системе для этого типа файлов (аналогично двойному щелчку в Проводнике).

### Показать файл в проводнике

Открывает Проводник Windows с автоматическим выделением файла книги. Удобно для быстрого поиска файла на диске.

### Показать каталог в проводнике

Открывает Проводник Windows в каталоге, где расположена книга.

### Пользовательские команды

Вы можете настроить собственные команды в файле конфигурации.

**Пример использования:**
1. Вызовите команду редактирования в FictionBook Editor (FBE) из контекстного меню
2. Отредактируйте файл в FBE
3. Сохраните изменения и закройте FBE
4. FB2 Toolbox автоматически обновит информацию о файле

> **Примечание:** Во время выполнения команды FB2 Toolbox будет недоступен до закрытия запущенного приложения.

### Считать заново

Обновляет информацию о файле из источника.

**Когда использовать:**
- После ручного редактирования файла в других программах (например, Notepad)
- Когда нужно обновить метаданные без перезагрузки списка
