Релиз 1.9.0 - 5 ноября 2025 года

> Автор изменений [Дмитрий](https://github.com/jonny3D)

### Добавлено
- Поддержка drag'n'drop файлов из FB2Toolbox в проводник (копирование-вставка)
- Поддержка drag'n'drop файлов между экземплярами FB2Toolbox (импорт файлов)
- Возможность группировки элементов по сериям
- Новые типы группировки
- Функция фильтрации и удаления файлов
- Возможность удаления файлов из списка и физического удаления файлов
- Переменные окружения, используемые при выполнении команды открытия
- Парсинг каталогов при drag'n'drop
- Парсинг файлов при drag'n'drop

### Изменено
- Обновление до Visual Studio 2022 и .NET Framework 4.8
- Оптимизация производительности
- Улучшена форма редактора свойств: автоматическое включение проверки обновлений при изменении текста
- Настройка конфигурации

### Исправлено
- Исправлено ограничение максимальной длины серии, которое иногда включало год издания
- Исправлен пропуск существующих файлов
- Исправлен парсинг имен файлов на кириллице
- Опциональная очистка списка перед drag'n'drop файлов
